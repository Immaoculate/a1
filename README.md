### If `DO_NOT_TOUCH.txt` isn't there

It's added automatically a few seconds after your repo is created, so if you
cloned very quickly you may have got the repo just before it arrived. Run:

```sh
git pull
```

and it will appear. If it still doesn't after a minute or two, post on the
forum — don't create the file yourself, a made-up one won't match.
